## 👨‍💻 About the Project

This is a responsive, modern, and interactive portfolio website built from scratch. It features a sleek dark mode design with glassmorphism effects, dynamic gradient text, and smooth animations to provide an engaging user experience.

The portfolio includes sections for:
- **Hero/Landing:** Quick introduction with download resume option and social links.
- **About:** Professional summary and passions.
- **Skills:** Technical skills across programming languages, web technologies, databases, and tools.
- **Projects:** Showcase of recent technical projects.
- **Experience & Education:** Timeline of professional and academic journey.
- **Certificates:** Certifications achieved.
- **Contact:** Form to get in touch.

## 🛠️ Built With

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styling with CSS Variables, Flexbox, CSS Grid, Glassmorphism, and responsive media queries.
- **JavaScript (Vanilla):** DOM manipulation, smooth scrolling, interactive elements, and custom animations.
- **FontAwesome & Devicon:** For scalable vector icons representing social platforms and tech stacks.
- **Google Fonts:** Utilizing 'Fira Code', 'Outfit', and 'Plus Jakarta Sans' for modern typography.

## ⚙️ How to Run Locally

1. **Clone the repository** (if applicable) or download the source code.
2. Ensure you have all the project files in the same directory (`index.html`, `styles.css`, `script.js`, `canvas-animation.js`, and `profile.jpg`).
3. Simply open the `index.html` file in any modern web browser.
   - Alternatively, you can use a local server like VS Code's "Live Server" extension for a better development experience.
